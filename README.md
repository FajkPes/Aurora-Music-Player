# Aurora Music Player

A local music player made for listening with customizable, audio-reactive visuals.

## Why Aurora?

Aurora is a local music player for people who want a configurable listening experience as well as audio-reactive visuals. It runs in a browser and keeps the music files under your control.

## Features

- Organize a local library, search, sort, favorite tracks and manage the playback queue.
- Use equalizer, waveform and ring visualizers with customizable backgrounds, colors and effects.
- Apply loudness normalization and adjust playback, interface and performance settings.
- Save and restore settings, profiles and a listening session; export playlists as M3U8.
- Use the compact player, keyboard shortcuts and supported media controls.

## Start listening

Download the ZIP from [Releases](https://github.com/FajkPes/Aurora-Music-Player/releases/latest), extract all files and open `index.html`. Add local audio files or a folder. The JavaScript files need to remain beside the HTML file.

In **Settings**, choose visualizers and effects, then adjust performance limits if your device struggles. Higher frame-rate limits may increase resource usage and depend on the display, browser and hardware. English is the default; Czech is available in settings.

The optional remembered library is stored in the browser, not in the application files. Use export and backup features when moving to another browser or computer. The older single-file 6.x releases remain available.
