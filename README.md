# Aurora Music Player

A local music player made for listening with customizable, audio-reactive visuals.

## Key features

- Play and organize a local music library with a queue and playlists.
- Customize visualizers, backgrounds and effects.
- Use loudness normalization and save listening settings.

## Get started

Download the ZIP from Releases and open `index.html`.
